\# Лабораторная работа № 2



\## Подготовка скриптов для создания таблиц и добавления данных



\### Описание проекта



Цель работы — автоматизировать процесс ETL (Extract, Transform, Load) для загрузки исходных данных в базу данных SQLite.



Python-скрипт `make\_db\_init.py` формирует SQL-скрипт `db\_init.sql`, содержащий команды создания таблиц и добавления данных. Скрипт `db\_init.bat` запускает генератор и выполняет SQL-команды с помощью SQLite.



\### Структура проекта



\* `make\_db\_init.py` — генерация SQL-скрипта;

\* `db\_init.bat` — запуск генерации и загрузки данных;

\* `db\_init.sql` — SQL-команды создания таблиц и добавления данных;

\* `movies\_rating.db` — база данных SQLite;

\* `movies.csv` — данные о фильмах;

\* `ratings.csv` — оценки пользователей;

\* `tags.csv` — теги фильмов;

\* `users.txt` — данные о пользователях;

\* `genres.txt` — данные о жанрах;

\* `occupation.txt` — данные о профессиях.



\### Требования к окружению



Для работы скрипта необходимы:



\* Python версии 3 (python 3.14.6);

\* SQLite 3 с доступной командой `sqlite3`;

\* Bash для выполнения shell-скрипта.



\### Запуск



Для создания и заполнения базы данных необходимо открыть терминал в каталоге `Task02` и выполнить команду:



```bash

bash db\_init.bat

```



В результате будет создана база данных `movies\_rating.db` с таблицами `movies`, `ratings`, `tags` и `users`.



При повторном запуске существующие таблицы удаляются и создаются заново.
