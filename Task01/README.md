# Лабораторная работа №1

## Структура файлов данных

В каталоге `Task01` находятся следующие файлы:

| Файл                | Назначение |
|---------------------|------------|
| `genres.txt`        | Список жанров фильмов |
| `movies.csv`        | Идентификатор фильмов, название, жанры |
| `occupation.txt`    | Список профессий |
| `ratings.csv`       | Идентификатор пользователя, идентификатор фильма, рейтинг, временная метка |
| `ratings_count.txt` | Значение идентификатора |
| `tags.csv`          | Идентификатор пользователя, идентификатор фильма, тег, временная метка |
| `users.txt`         | Информация о пользователях |
| `sqlite.txt`        | Данные по SQLite |
